Here are a few new feature ideas for your Open Folder in New VS Code extension:

1. Open Folder in Specific VS Code Version
Allow users to choose whether to open the folder in Stable, Insiders, or another installed VS Code flavor.

2. Open Folder in New Window With Profile
Let users select a VS Code profile (e.g., "Work", "Debug", "Minimal") when opening a folder in a new window.

3. Open Folder and Run Command
After opening the folder in a new window, automatically run a user-defined command (like npm install, git pull, or open a specific file).

4. Favorites/Quick Access
Allow users to mark certain folders as favorites and quickly open them in a new window from a command palette or sidebar.
